## 📌 Question A1: Diode Operating Voltage (Newton-Raphson)

### 📐 Equation
Find the operating voltage $V$ that satisfies the diode characteristic equation:
$$f(V) = 10^{-12} \left(e^{\frac{V}{n V_T}} - 1\right) + \frac{V}{R} - I_L = 0$$

### 📊 Given Parameters
- **Initial Guess:** $V_0 = 0.65\text{ V}$
- **Ideality Factor ($n$):** $1.8$
- **Thermal Voltage ($V_T$):** $0.02585\text{ V}$
- **Resistance ($R$):** $0.5\text{ k}\Omega = 500\ \Omega$
- **Light-Generated Current ($I_L$):** $0.2\text{ mA} = 0.0002\text{ A}$

### 🎯 Tasks & Requirements
1. Formulate $f(V)$ and its analytical derivative $f'(V) = \frac{df}{dV}$ for the **Newton-Raphson** method.
2. Implement Newton-Raphson method with stopping criterion $|\varepsilon_a| \le 0.0001\%$.
3. **Tabular Output:** Print iteration table with column headers:
   `Iter` | `V_i` | `f(V_i)` | `f'(V_i)` | `V_{i+1}` | `ea (%)`

## 📌 Question B1: Transcendental Multi-Root Scanner (Bisection)

### 📐 Function
$$f(x) = 0.6 \ln(x + 1) - C \sin(1.7x) - 0.08 x^2 - 0.08 = 0$$
*(Default coefficient $C = 1.0$ unless specified otherwise)*

### 📊 Domain & Parameters
- **Domain:** $0 \le x \le 10$
- **Incremental Step Size:** $\Delta x = 0.1$
- **Stopping Criterion:** $|\varepsilon_a| \le 0.0001\%$

### 🎯 Tasks & Requirements
1. **Plotting:** Plot the function $f(x)$ in the interval $0 \le x \le 10$ to visualize root locations.
2. **Interval Isolation:** Write a scanner to find all sub-intervals $[x_i, x_{i+1}]$ of step size $\Delta x = 0.1$ where a sign change occurs ($f(x_i) \cdot f(x_{i+1}) < 0$).
3. **Bisection Solver:** Execute the Bisection method on **every** isolated sign-change interval.
4. **Root Extraction:** Compute all real roots in the domain.
5. **Tabular Output:** Print an iteration table for each root following standard lecture slide formatting (`Iter`, `xl`, `xu`, `xr`, `ea (%)`, `f(xr)`).
6. **Conceptual Analysis Question:**
   - *Question:* What problem would occur if the Bisection method were run just once over the entire $[0, 10]$ domain instead of sub-intervals?
   - *Answer Summary:*
     1. **Sign Cancellation:** $f(0) < 0$ and $f(10) < 0$, so $f(0) \cdot f(10) > 0$. Bisection fails to start because no sign change is detected across the full domain.
     2. **Singular Discovery:** Even if $f(a) \cdot f(b) < 0$, Bisection can only converge to a single root, missing all other roots in the domain.

## 📌 Question B2: Pathological Rational Function (Bisection & Discontinuity Handling)

### 📐 Function
$$f(x) = \frac{(x - 2.5)^2 (x + 1.052)}{x - 3.551}$$

### 📊 Domain & Parameters
- **Domain:** $-2 \le x \le 5$
- **Step Size:** $\Delta x = 0.1$
- **Stopping Criterion:** $|\varepsilon_a| \le 0.0001\%$

### 🎯 Tasks & Requirements
1. **Plotting:** Plot the function $f(x)$ over $[-2, 5]$. Handle/mask the vertical asymptote at $x = 3.551$.
2. **Candidate Scanning:** Search the interval with step size $\Delta x = 0.1$ to identify root candidates:
   - **Direct Root Candidate:** Points where $|f(x)| \le 10^{-8}$.
   - **Interval Candidate:** Sub-intervals where $f(x_i) \cdot f(x_{i+1}) < 0$.
3. **Bisection Execution:** Run the Bisection method on all candidate intervals.
4. **Singularity Guard:** If an undefined value (division by zero / asymptote crash) is encountered during Bisection, immediately terminate that run.
5. **Acceptance Threshold:** Accept root estimates $x_r$ **only if** $|x_r| \le 10^{-6}$ *(Literal exam specification filter)*.
6. **Tabular Output:** Print full iteration tables for all Bisection runs.
7. **Candidate Verdict Summary Table:** Print candidate list with: Candidate Index, Type (Direct / Interval), Estimated $x_r$, $f(x_r)$, and Acceptance Verdict (`ACCEPT` / `REJECT`).
8. **Conceptual Analysis Question (3–4 Sentences):**
   - Explain:
     1. Why one true root ($x = 2.5$) does not produce a sign change (double root / even multiplicity touches the axis without crossing).
     2. Why one sign-change interval (around $x = 3.551$) contains no root (vertical asymptote discontinuity jumps from $-\infty$ to $+\infty$).
     3. Why checking function residuals $|f(x_r)|$ is essential before accepting Bisection results (to catch false roots generated by asymptotic sign flips).

## 📌 Question C2: Log-Scale Convergence & Stagnation Analysis (Bisection vs. False Position)

### 📐 Equation
$$f(x) = \ln(x) = 0$$

### 📊 Domain & Parameters
- **Domain:** $10^{-4} \le x \le 10^4$
- **Stopping Criterion:** $|\varepsilon_a| \le 0.0001\%$

### 🎯 Tasks & Requirements
1. **Logarithmic Plotting:** Plot $f(x) = \ln(x)$ on a logarithmic scale (`plt.xscale('log')`).
2. **Boundary Verification:** Mathematically verify the sign change condition over $[10^{-4}, 10^4]$:
   - $f(10^{-4}) = \ln(10^{-4}) \approx -9.21034 < 0$
   - $f(10^4) = \ln(10^4) \approx 9.21034 > 0$
   - $f(x_l) \cdot f(x_u) < 0 \implies$ valid bracket.
3. **Bisection Execution:** Apply the Bisection method on $[10^{-4}, 10^4]$.
4. **False Position Execution:** Apply the False Position method on $[10^{-4}, 10^4]$.
5. **Update Counting:** Count and track how many times the lower bound ($x_l$) and upper bound ($x_u$) are updated in each method.
6. **Tabular Output:** Print iteration tables for both methods.
7. **Comparison Table:** Print a side-by-side comparison table summarizing:
   - Method Name
   - Estimated Root ($x_r$)
   - Total Iteration Count
   - Final $f(x_r)$
   - Bound Update Counts ($x_l$ updates / $x_u$ updates)
8. **Written Explanation Questions:**
   - **a) Faster Method:** Which method converged faster for this problem? *(Bisection: 34 iterations vs. False Position: 126 iterations)*.
   - **b) False Position Speed Guarantee:** Why is False Position not guaranteed to be faster than Bisection? *(Because heavy curvature/asymmetry causes one-sided endpoint stagnation, turning bracketed interpolation into a slow linear progression)*.
   - **c) Endpoint Stagnation Cause:** Why did one endpoint ($x_l$) receive **0 updates** throughout False Position? *(Because $f(x) = \ln(x)$ is strictly concave down ($f''(x) < 0$). The secant line always intersects to the right of the true root $x=1.0$, giving $f(x_r) > 0$, so $x_u$ updates every step while $x_l$ stays stuck at $10^{-4}$)*.
