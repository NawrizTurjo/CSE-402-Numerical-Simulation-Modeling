# Extras

## Purpose

This folder contains older or extra practice files from the same topics.

Use these files as backup examples or rough practice versions. The cleaner topic-wise versions are in the main folders:

```text
random_number/
monte_carlo/
simulation/
Independence/
ks_test/
```

## Files

### `random_number.py`

Contains mixed random-number code:

```text
LCG generation
period checking
K-S test
Chi-Square test
autocorrelation test
Monte Carlo examples
```

### `single_server_queue.py`

Cleaner single-server queue simulation.

It calculates:

```text
average delay
average number in queue
server utilization
total simulation time
```

### `q1.py`, `q2.py`, `q3.py`, `q4.py`, `finalq.py`

Practice variants for queue simulation questions.

Common ideas:

```text
arrival event
departure event
event list
queue length
server busy/idle
area under Q(t)
area under B(t)
```

## Advice

For exam preparation, study the topic folders first. Use `extras/` only when you want more practice examples.
